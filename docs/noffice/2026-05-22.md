  - **참조**: [GitHub Issue #21](https://github.com/NSoft-America-Inc/NAtlas/issues/21)

  - **성과**: Zustand 전역 UI 스토어에 검색 텍스트 브릿지를 구성하여 탭 전환 시 과거 검색이 자동 기동되도록 연계했습니다. WikiViewer 내에 현재 문서의 태스크 슬러그와 매핑되는 과거 Q&A 카드 목록을 제공하여 Query 탭으로의 매끄러운 흐름을 보장하며, WikiGraph 컴포넌트에 탐색 이력 데이터를 바인딩해 누적 조회 빈도가 높은 노드의 반지름 스케일과 네온 글로우 반경이 비례하여 확장 렌더링되는 시각적 가독성 체계를 고도화했습니다.

- **[#13] WikiGraph 인터랙티브 탐색 및 슬라이드서랍 개편 (WIKI UX 대전환)**
  - **개요**: 기존 지식 네트워크 그래프가 전체 배경에 중첩되어 문서 본문 뷰어 오픈 시 가독성이 저하되었으며, 마우스 드래그(노드 이동)와 문서 단일 클릭 탐색 간에 물리 인터랙션 충돌이 발생해 사용성이 크게 떨어지던 상황을 개편하고자 함.
  - **성과**: 상단 헤더에 지식 그래프 ON/OFF 토글 제어를 마운트하고, 우측에서 300ms 동안 슬라이드인하는 absolute 그래프 서랍 패널로 구조를 개편하였습니다. 그래프 서랍 활성화 시 본문이 가려지지 않도록 동적 Padding-Right 전이(`pr-0` ➔ `pr-[650px]`)를 주어 병렬 레이아웃을 구현했으며, 마우스 다운/업 거리(`dragDist < 5px`) 연산을 반영해 물리 드래그와 단일 클릭을 완벽 분리하여 오작동 없는 인터랙티브 조회 및 `forceOpen` 문서 즉시 로드를 연동했습니다.
  - **참조**: [GitHub Issue #13](https://github.com/NSoft-America-Inc/NAtlas/issues/13)
