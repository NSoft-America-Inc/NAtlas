- **[#13] WikiGraph 인터랙티브 탐색 UX 전면 개편** *(진행 중 이슈, 오늘 주요 구현 완료)*
  - **개요**: 기존 WikiGraph는 전체 노드를 한꺼번에 렌더링해 가독성이 낮고 물리 시뮬레이션이 영구 실행되어 노드가 계속 움직이는 문제가 있었음. 탐색 흐름의 구조화 필요.
  - **성과**:
    - **Depth 탐색 구조**: 초기에는 프로젝트 노드만 표시. 클릭 시 태스크 → 문서 순으로 단계적 전개.
    - **포커스 모드**: 프로젝트 선택 시 나머지 프로젝트 노드 자동 숨김 → 집중 탐색 가능.
    - **상위 레이어 복귀 버튼**: 포커스·확장 상태에서 초기 프로젝트 뷰로 즉시 복귀.
    - **호버 툴팁**: 프로젝트 노드 위에 마우스를 올리면 태스크 수, 작업계획서/완료보고서/wiki 개수, 최근 태스크 4개를 글래스모피즘 카드로 표시.
    - **물리 안정화**: Alpha 감쇠 적용으로 시뮬레이션이 약 2초 후 자동 정지. Pause/Play 버튼으로 수동 고정 가능.
  - **참조**: [GitHub Issue #13](https://github.com/NSoft-America-Inc/NAtlas/issues/13)
