## ✅ 완료 (Done)

- **[#17] NAtlas Resizable Panels 드래그 영역 조절 UX 고도화 및 Layout.tsx 핫픽스**
  - **개요**: NAtlas 데스크탑 지식 탐색기의 사용성(UX)을 대폭 개선하기 위해 좌측 메뉴와 우측 본화면(Documents 탭의 파일 목록 및 마크다운 뷰어) 간의 경계선을 마우스 드래그로 조절할 수 있는 Resizable Panels 기능을 구축했다. 또한 레이아웃 해석 시점에 이중 Export로 인해 발생하던 구문 오류와 컴포넌트 임포트 누락 런타임 에러를 신속하게 핫픽스 완료했다.
  - **성과**: 영역 너비 가변 상황에서도 React Virtual DOM의 렌더링 무결성을 그대로 유지하여, 목록의 스크롤 오프셋 및 열려 있는 아코디언 상태가 초기화되지 않고 완벽하게 보존되는 무중단(State-Preserved) 레이아웃을 제공했다. 또한 60초 주기 자동 백그라운드 인덱싱 스케줄러를 Sidecar에 성공적으로 이식하여 백엔드 문서 동기화 효율성을 증대했다. 본 이슈는 최종 완료 검수를 통과하여 closed 상태로 마감되었다.
  - **참조**: [#17](https://github.com/NSoft-America-Inc/NAtlas/issues/17)
