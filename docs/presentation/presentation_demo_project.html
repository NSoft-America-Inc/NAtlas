⚡ `--heal` 자동 포맷 치유로 본문 보존 및 커밋 패스

힐러 알고리즘이 가동되어, 개발자가 어설프게 남겨둔 플레이스홀더를 지워내고

  • 알맹이(국문 서술) 데이터의 100% 보존:
    작성한 알짜배기 기술 의사결정 내용은 전혀 손대지 않는 영리한 힐링 기전
  • Fuzzy Header 정상화 매핑:
    국문이나 오타로 틀어진 H2 섹션을 영문 정식 H2 골격으로 재배치 자동 조치
  • E2E 지식 파이프라인의 안전 진입:
    안정적으로 린트 패스를 받고, 커밋에 최종 골인하여 SwarmVault RAG 색인을 위해 귀착
