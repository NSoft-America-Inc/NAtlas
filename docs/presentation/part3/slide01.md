# 한 번 설치로 끝납니다 — 그 다음부터는 자동입니다

## 1. 화면 정의 및 레이아웃 (Layout Specification)

- **레이아웃 구조**: 설치 → 자동화 두 단계를 보여주는 **Setup Then Auto Layout**. 좌측에 설치 명령어, 우측에 그 이후 자동으로 작동하는 것들 목록.
- **비주얼 및 컴포넌트 구성**:
  - **좌측 (설치, 터미널 스타일)**:

    ```
    $ git clone [프로젝트]
    $ npm install

    ✅ NStack 자동 검사기 설치 완료
    ```

  - **중앙 화살표**: "이 다음부터는 자동"
  - **우측 (자동 작동 항목, 에메랄드)**:
    - `✅ 커밋할 때마다 문서 자동 검사`
    - `✅ 문제 발견 시 저장 차단`
    - `✅ 어디가 문제인지 자동 표시`
  - **하단 배지**: "개발자가 따로 설정할 것 없음 / 팀 전체에 동일하게 적용"

## 2. 실질적 본문 내용 (Exact Slide Content)

### NStack을 팀에 도입하는 방법 — 복잡하지 않습니다

팀에 새로운 도구를 도입할 때 가장 큰 장벽: "설치와 설정이 복잡하다."

NStack은 이것을 한 번으로 끝냅니다:

**1단계: 프로젝트를 클론하고 패키지를 설치합니다**

```
git clone [프로젝트]
npm install
```

**→ 끝입니다.** 이 명령어 하나가 실행되는 순간, NStack 자동 검사기가 함께 설치됩니다.

**그 다음부터는 자동입니다:**

- 팀원이 코드를 저장소에 올릴 때마다 → 자동으로 문서를 검사합니다
- 문제가 있으면 → 저장이 차단되고 이유를 알려줍니다
- 문제가 없으면 → 그냥 통과됩니다

**팀원마다 따로 설정할 필요 없습니다.** 프로젝트에 한 번 적용되면 팀 전체에 동일하게 적용됩니다. 새로 합류한 팀원도 `npm install` 하면 동일한 환경이 됩니다.

## 3. 스피치 노트 (Aside Speaker Notes)

_"NStack을 팀에 도입하는 방법입니다. git clone하고 npm install, 이게 전부입니다. 이 명령어가 실행되는 순간 자동 검사기가 함께 설치됩니다. 그 다음부터는 팀원이 코드를 올릴 때마다 자동으로 문서 검사가 실행됩니다. 팀원마다 따로 설정할 필요가 없습니다. 새로 합류한 팀원도 npm install 하면 동일한 환경이 됩니다. 도입 장벽이 낮습니다. 이제 실제로 어떻게 작동하는지 보여드리겠습니다."_
