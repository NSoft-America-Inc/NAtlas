# Slide 27: 신규 개발 시작 - 에이전트 프롬프트 (실제 화면 띄우기 1)

## 1. 화면 정의 및 레이아웃 (Layout Specification)

- **레이아웃 구조**: 개발자가 에디터 상에서 AI 에이전트에게 내린 날것의 프롬프트와 지시 사항을 현실감 있게 박제하는 **VS Code 프롬프트 쉘 레이아웃 (VS Code Prompt Shell Layout)**.
- **비주얼 및 컴포넌트 구성**:
  - **좌측 비주얼**: VS Code 에디터 인터페이스를 완벽 재현한 3D 다크 프롬프트 카드. 좌측 파일 트리에 `index.html`, `script.js` 노드가 나열되어 있고, 본문 윈도우에는 개발자가 직접 에이전트에게 건넨 프롬프트 1의 마크다운 텍스트와 핵심 강제 명령어들이 에메랄드색 네온 형광펜 글로우로 정밀하게 하이라이트 처리된 SVG 탑재.
  - 실제 입력된 데이터의 무결성을 입증하는 **⌨️ PROMPT DATA CAPTURE** 라벨 적용.

## 2. 실질적 본문 내용 (Exact Slide Content)

### ⌨️ "개발을 시작하기 전에, 반드시 order.md를 작성하고 승인을 받아라"

에이전트와의 협업에서 정합성을 확보하기 위한 첫 번째 규칙은 "말을 섞기 전에 계획을 글로 남기게 하라"는 것입니다. 아래 텍스트는 실제 NStack 환경에서 에이전트에게 신규 피처 구현을 지시하며 입력창에 그대로 주입한 실물 프롬프트 데이터입니다.

- **💬 에이전트 입력 프롬프트 1 [Actual Prompt Data]**:
  ```markdown
  "현재 NStack 프레임워크 셋업 이후 첫 피처 구현으로, 사용자들이 브라우저 상에서
  본인의 할 일을 추가, 토글, 삭제하고 전체/진행중/완료 상태를 실시간 대시보드로
  집계해 볼 수 있는 모던한 Todo Dashboard를 구현해줘.
  
  개발을 시작하기 전에 반드시 NStack 템플릿 규격에 맞춰 order.md를 작성하고
  나에게 먼저 제출하여 승인을 받아라."
  ```
- **⚡ 프롬프트가 촉발하는 에이전트의 인지 바인딩 [Cognitive Binding]**:
  - 에이전트는 이 프롬프트를 인지하는 즉시, 날것의 소스 코드를 생성하는 동작을 중단하고 저장소 루트의 `AGENTS.md` 지침에 따라 템플릿 무결성이 갖춰진 `order.md` 계획 초안부터 작성하도록 두뇌의 인지 체계를 강제 정렬합니다.

## 3. 스피치 노트 (Aside Speaker Notes)

*"화면에 띄워진 이 텍스트가 실제 AI 에이전트에게 주입된 날것의 1차 프롬프트 실물입니다. 'Todo Dashboard를 구현하라'는 기능 요구사항과 함께, 가장 하단에 핵심 지시어가 박혀 있습니다. 바로 '코드를 짜기 전, 템플릿 규격에 맞춰 order.md를 작성해 나에게 먼저 승인을 받아라'는 것입니다. NStack의 강력한 룰셋을 머리에 이식받은 AI 에이전트는 이 지시를 삼키는 순간, 무작정 코드를 마구잡이로 짜서 흩뿌려놓던 습관을 멈추게 됩니다. 차분히 에디터를 열고 Git 브랜치 전략과 요구 설계, 완료 기준을 적을 준비를 하며 `order.md` 파일부터 원자적으로 개설하는 안전한 인지 루프 속으로 진입하게 됩니다."*
