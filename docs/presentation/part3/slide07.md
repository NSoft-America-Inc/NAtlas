# 실제 화면 ① — Claude Code에 이렇게 지시합니다

## 1. 화면 정의 및 레이아웃 (Layout Specification)

- **레이아웃 구조**: 실제 터미널/에디터 화면을 중심으로 보여주는 **Screen Capture Layout**. 화면이 메인, 설명은 보조.
- **비주얼 및 컴포넌트 구성**:
  - **중앙 (실제 화면 캡처 영역)**: Claude Code 터미널 화면. 실제 프롬프트 입력 장면.
  - **좌측 설명 패널 (작게)**:
    - "order.md를 먼저 작성합니다"
    - "이 파일을 AI에게 전달합니다"
    - "AI가 맥락을 이해하고 시작합니다"
  - **상단 배지**: "실제 화면" (라이브 시연 표시)

## 2. 실질적 본문 내용 (Exact Slide Content)

### 실제 프롬프트 — 이렇게 지시합니다

Claude Code에 전달하는 실제 내용:

```
order.md를 보고 작업해주세요.

이 파일에 오늘 만들 것, 왜 만드는지,
어떤 파일을 만들지, 어디까지 하면 완료인지가
모두 적혀 있습니다.

order.md의 범위 안에서만 작업해주세요.
```

**포인트:**
- 긴 설명을 AI에게 직접 타이핑하지 않습니다
- order.md 하나를 가리키면 됩니다
- AI는 그 문서를 읽고 맥락을 파악합니다

AI가 이 지시를 받으면 — order.md를 읽고, 무엇을 만들어야 하는지 이해하고, 범위 안에서 코드를 작성하기 시작합니다.

*[이 슬라이드에서 실제 화면을 띄워 시연합니다]*

*"실제 화면을 보시겠습니다. Claude Code에 지시하는 방법은 간단합니다. order.md를 보고 작업해달라고 합니다. 긴 설명을 직접 타이핑할 필요가 없습니다. 문서 하나를 가리키면 됩니다. AI는 그 문서를 읽고 맥락을 파악하고 작업을 시작합니다. 지금 실제로 보여드리겠습니다."*
