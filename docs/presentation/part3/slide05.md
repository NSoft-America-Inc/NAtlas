## 2. 실질적 본문 내용 (Exact Slide Content)

### 이제 직접 보여드리겠습니다 — 실제로 작동하는 장면입니다

설명은 여기까지입니다. 지금부터는 실제 화면입니다.

**시연 1: 신규 개발**

- Vanilla JavaScript로 Todo 대시보드를 처음부터 만듭니다
- NStack 없이 그냥 만드는 게 아닙니다 — order.md를 먼저 쓰고, AI가 그걸 보고 만듭니다
- 끝나면 wiki.md가 자동으로 생성됩니다

**시연 2: 마이그레이션**

- 시연 1에서 만든 Vanilla JS 앱을 React로 포팅합니다
- 핵심 포인트: 시연 1의 지식이 시연 2에 자동으로 이어집니다
- AI가 "왜 이렇게 만들었는지"를 알고 있어서, 처음부터 다시 설명하지 않아도 됩니다

**이 두 시연이 보여주는 것**:

- NStack이 실제로 어떻게 작동하는지
- 지식이 어떻게 이월되는지
- 개발자가 실제로 무엇을 하고 AI가 무엇을 하는지
