## 2. 실질적 본문 내용 (Exact Slide Content)

### 시연 1: Vanilla JavaScript로 Todo 대시보드 만들기

오늘 만들 것: **할 일 목록 관리 앱 (Todo Dashboard)**

기능:

- 할 일 추가 / 완료 체크 / 삭제
- 완료된 항목 통계
- 로컬 저장 (페이지 새로고침해도 유지)

**오늘 시연에서 보여드릴 것:**

1. **order.md 작성** — "이 앱을 왜 만드는지, 어떻게 만들 것인지"를 5분 안에 정리합니다
2. **AI에게 지시** — order.md를 Claude Code에 전달하고 구현을 요청합니다
3. **AI가 구현** — 실제 코드가 만들어지는 장면을 보여드립니다
4. **문서 자동 생성** — wiki.md와 report.md가 어떻게 만들어지는지 보여드립니다

코드를 짜는 데 몇 분이 걸리는지, 그리고 문서가 얼마나 자동으로 만들어지는지 — 직접 보시면 됩니다.
