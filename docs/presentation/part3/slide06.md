# Slide 26: [시연 1단계] 신규 개발 - Vanilla JS Todo Dashboard

- **레이아웃 구조**: 정교한 정적 UI 와이어프레임과 구현 사양 카드가 대조를 이루며 라이브 시연의 오프닝을 알리는 **대시보드 와이어프레임 레이아웃 (Dashboard Wireframe Layout)**.
- **비주얼 및 컴포넌트 구성**:
  - **좌측 비주얼**: 황금색 네온으로 빛나는 Todo App 대시보드 UI 레이아웃 와이어프레임. 상단 헤더, 할 일 입력 필드, 리스트 영역, 그리고 하단에 집계 카드 3종(전체, 진행 중, 완료 수)이 깔끔한 격자 격눈으로 묘사된 동적 입체 SVG 장착. UI 내에 **`[Todo Dashboard Wireframe]`** 라벨과 각 컴포넌트의 테두리가 반짝이는 글로우 효과 적용.
  - 최초 프로토타입 설계 규격을 증명하는 **🎨 PROTO UI LAYOUT SPEC** 라벨 점등.

## 2. 실질적 본문 내용 (Exact Slide Content)

### 🎨 외부 라이브러리 없이, 바닥부터 탄탄하게 설계되는 바닐라 UI

듀얼 라이브 데모의 첫 번째 관문은 **[시연 1단계: 신규 피처 구현]**입니다. 복잡한 모던 웹 프레임워크나 외부 의존성을 100% 배제하고, 웹 브라우저가 기본적으로 지원하는 HTML5, CSS3, Vanilla JavaScript만을 사용하여 동작하는 정밀한 **할 일 관리 대시보드(Todo Dashboard)**를 구축하는 여정입니다. 

- **🛠️ 구현 대상 기능 명세 [Todo Dashboard Core Specs]**:
  - **Task Add & Remove**: 사용자가 입력창에 할 일을 적고 Add 버튼을 누르면 실시간으로 리스트 노드가 추가되고, 휴지통 버튼 클릭 시 리스트에서 제거됩니다.
  - **Task Toggle & Filter**: 할 일 항목을 체크하여 완료 상태로 전환하는 토글 기능 및 전체/진행중/완료 목록만 추려서 볼 수 있는 실시간 라디오 필터 뷰포트를 제공합니다.
  - **State Analytics**: 현재 목록에 쌓여 있는 할 일들의 수치를 합산하여 `전체(Total)`, `진행중(Active)`, `완료(Completed)`의 3대 메트릭 대시보드로 실시간 계산 및 렌더링합니다.
- **🛡️ NStack 설계 가두리 [Constraints binding]**:
  - 에이전트가 코딩을 짤 때 무분별하게 외부 패키지를 설치하거나 엉뚱한 CSS 테일윈드를 쓰지 못하도록, **`order.md`**를 통해 순수 Vanilla JS 환경으로 경계를 단단히 옭아맨 상태로 개발에 진입합니다.

## 3. 스피치 노트 (Aside Speaker Notes)

*"실전 듀얼 데모의 첫 단계, 바로 바닐라 JS Todo Dashboard 신규 개발에 착수하는 장면입니다. 프레임워크의 도움 없이 순수한 웹 표준 기술로만 동작하는 할 일 관리 대시보드를 구축하려 합니다. 할 일의 입력, 삭제, 토글 상태 변환은 물론이고 하단에 전체, 진행 중, 완료 카운트를 실시간으로 집계해 주는 대시보드 분석판까지 완비된 고기능성 UI입니다. 여기서 가장 중요한 포인트는 이 모든 개발을 시작하기 직전, AI 에이전트의 개발 범위를 튼튼하게 바인딩하는 NStack의 설계 가두리 통제가 작동한다는 점입니다. 에이전트가 제멋대로 엉뚱한 라이브러리를 추가하거나 아키텍처를 뒤흔들지 못하도록 `order.md`를 통해 명확한 Vanilla JS 요구 사양의 경계를 단단히 옭아매고 코딩을 지시하는 첫 삽을 뜹니다."*
