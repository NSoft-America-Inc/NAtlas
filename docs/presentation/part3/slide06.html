SwarmVault RAG 기반 로컬 지식 색인 아키텍처

로컬 SQLite DB 기반 상태/이력/빌드 통계 연동

🏛️ SQLite DB를 활용한 정교한 이력 관리 및 캐싱

SwarmVault는 단순히 마크다운 파일을 검색하는 RAG에 그치지 않고,
로컬 SQLite DB와의 철저한 상태 데이터 동기화를 통해 질문 이력과 색인 통계를 완벽 추적합니다.

  • task_history 테이블 관리:
    에이전트가 어떤 의사결정과 질문을 거쳐 코딩을 진행했는지 모든 시맨틱 질문 히스토리 기록.
  • build_logs 테이블 캐싱:
    백그라운드 스케줄러가 색인을 갱신할 때 생성한 컴파일 빌드 통계와 타임스탬프 로그를 저장하여 증분 스캔 가속화.
  • 시각화 통합 대시보드:
    로컬 SQLite에 적재된 통계 데이터가 NAtlas UI와 API를 통해 즉각 연동되어 실시간 색인 컴파일 상태 그래프 제공.
SwarmVault RAG 기반 로컬 지식 색인 아키텍처 NSoft America, Inc.
"단순 텍스트 시맨틱 매핑을 넘어, SQLite DB의 task_history와 build_logs를 정교하게 연동하여 증분 빌드 속도를 비약적으로 끌어올리고 대시보드 시각화의 원천 데이터로 사용합니다."
