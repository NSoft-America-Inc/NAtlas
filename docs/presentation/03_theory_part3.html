SwarmVault RAG: 스마트 큐레이션 메커니즘

📖 도서관 전체 복사 vs 사서 비서의 1초 큐레이션

SwarmVault RAG는 소스코드 정보와 과거의 의사결정 맥락을 비효율적으로 통째 로딩하는 대신,
지금 필요로 하는 딱 1장의 요약 위키 지식만을 큐레이션하여 제공하는 스마트 RAG 엔진입니다.

  • Naive 방식의 재앙:
    도서관에 있는 수천 권의 책(소스코드 전체)을 매번 통째로 인쇄 복사해서 에이전트의 책상 위에 부어버려 토큰 비용 낭비와 메모리 유실 발생.
  • SwarmVault RAG의 해결책:
    에이전트가 질문을 던졌을 때, 사서 비서(RAG)가 도서관에서 딱 맞는 핵심 요약 캡슐(1장의 Citation 문서)만 찾아 1초 만에 책상에 쏙 얹어주는 고효율 정보 제공.
  • 로컬 초경량성:
    무거운 외부 클라우드 RAG 솔루션 없이, 로컬 단독으로 작동하여 샌드박스의 완벽한 보안과 초고속성 유지.

Naive 로드 vs SwarmVault RAG 정밀 대조

✨ SwarmVault RAG (스마트 사서 방식)

필요한 설계 의도와 히스토리를 콕 집어 시맨틱 인출 후 컨텍스트 창에 Citadel 보존

  • 비용 요금: Naive 대비 평균 95.29% 극적인 토큰 세이빙 완수
  • 인지 속도: 3초 이내 도달 (1초 미만의 고속 시맨틱 매핑 인출)
  • 메모리 보존: 컨텍스트를 깨끗하게 유지해 장기 세션에서의 오작동 전면 차단
  • 인프라: 외부 API 통신 없는 로컬 CLI 기반 초경량 구동 (SQLite 캐시)

⚠️ Naive 전체 로드 (무지성 복사 방식)

사소한 수정을 할 때도 수천 줄의 거대 전체 코드를 프롬프트에 반복해서 쏟아붓는 방식

  • 비용 요금: 매번 전체 코드를 우겨넣어 기하급수적으로 폭증하는 토큰 사용량
  • 인지 속도: 수천 라인의 무거운 파싱으로 인한 인지 딜레이 및 병목 현상
  • 메모리 보존: 대화 이력이 금방 가득 차서 과거의 중대 설계 의도를 완전 망각
  • 안정성: 컨텍스트 포화로 인한 환각(Hallucination) 및 엉뚱한 레거시 훼손 코드 양산

스마트 사서 방식의 4대 핵심 구동 메커니즘

📉 비용요금: 95.29% 압축 필터링

수만 단어의 코드 전체를 매번 LLM에 우겨넣어 비용을 폭증시키는 Naive 로드와 달리, 스마트 사서는 시맨틱 유사도 분석을 거쳐 질문에 답하는 데 필요한 핵심 1페이지 Citation(지식 조각)만 검출하여 LLM에 주입하므로 토큰 비용이 극적으로 절감됩니다.

⚡ 인지속도: 0.2초 로컬 인덱싱 가속

수천 라인의 원시 텍스트를 LLM이 처음부터 한 줄씩 읽고 파싱하는 버퍼링 렉(3초 이상)을 해소합니다. 미리 컴파일된 로컬 SQLite 벡터 데이터베이스 인덱스에서 시맨틱 수학적 거리가 가장 가까운 요약본을 0.2초 이내로 즉각 타겟팅 인출하여 딜레이가 없습니다.

🛡️ 메모리 보전: 컨텍스트 순도 수호

불필요한 레거시 코드와 무관한 온갖 잡음 스팸 정보들이 LLM의 한정된 컨텍스트 창을 오염시키는 것을 원천 차단합니다. 작업 기억 공간(Working Memory)을 순수하게 유지함으로써, 대화 세션이 아무리 길어져도 에이전트 본래의 시스템 프롬프트 규칙과 설계 의도가 희석되지 않고 확고히 영구 보전됩니다.

🔌 인프라: 로컬 단독 초경량 구동

외부 유료 RAG 클라우드 API 가입이나 무거운 외부 벡터 DB 인프라 세팅이 전혀 필요 없습니다. 로컬 디스크 내의 초경량 SQLite 데이터베이스와 단독 구동 CLI 도구만으로 완전히 독자 실행되며, 소스코드가 외부망으로 1byte도 유출되지 않아 전사 지식 보안 샌드박스를 완벽 충족합니다.

SwarmVault RAG 3대 핵심 CLI 구동 명령어

🛠️ 로컬 터미널과 백엔드 서버를 지탱하는 3대 CLI

SwarmVault RAG는 백그라운드 uvicorn 백엔드가 서브프로세스로 로컬 CLI 도구를 호출하는 형태로 완벽하고 탄탄하게 결합되어 구동됩니다.

  • 1. swarmvault ingest:
    로컬 LLMWiki 마크다운 파일들의 디렉토리 구조를 고속 탐색하여, 변경되거나 신규 추가된 아티팩트를 수집 및 1차 파싱.
  • 2. swarmvault compile:
    수집된 위키 노드를 시맨틱 맵으로 변환하고 인덱싱 데이터를 로컬 Vault 디렉토리에 캐싱 빌드.
  • 3. swarmvault query:
    "Zustand 설계 의도"와 같은 시맨틱 설계 질문이 들어왔을 때, 인덱싱된 캐시에서 관련도가 높은 지식 캡슐(Citation)을 1초 만에 색인 추출.

60초 Smart Background Scheduler 자동 빌드

⏰ 수동 명령어 입력 없는 60초 주기 무중단 자동 동기화

개발자가 의식해서 색인 명령어(ingest/compile)를 매번 실행할 필요가 전혀 없도록,
NAtlas Python 백엔드 내부의 데몬 스레드가 60초마다 스마트 자동 컴파일을 가동합니다.

  • LLMWiki 디렉토리 무중단 스캔:
    백그라운드 스케줄러가 파일 시스템의 위키 수정 사항을 60초 간격으로 조용히 자동 감지.
  • 자동 증분 컴파일 기전:
    변경점이 확인되는 순간 자동으로 uvicorn 백엔드가 `ingest` + `compile`을 실행하여, 로컬 지식 Vault 데이터 베이스를 실시간 최신화.
  • 개발자 방해 제로(Frictionless):
    터미널에 명령어를 칠 필요 없이, 코드를 수정한 뒤 1분 이내에 NAtlas에 모든 시맨틱 지식과 그래프가 반영 완료되는 고도화된 자동화.
