# Slide 31: 마이그레이션 기동 - 연계 프롬프트 (실제 화면 띄우기 3)

## 1. 화면 정의 및 레이아웃 (Layout Specification)

- **레이아웃 구조**: 개발자가 에이전트에게 2단계 마이그레이션 및 이전 단계 지식 RAG 탐색을 명령하는 **VS Code 프롬프트 쉘 레이아웃 (VS Code Prompt Shell Layout)**.
- **비주얼 및 컴포넌트 구성**:
  - **좌측 비주얼**: 사파이어 다크 무드의 VS Code 프롬프트 윈도우. 입력 대화창 내에 개발자가 주입한 마이그레이션 연계 프롬프트 2의 텍스트가 표시되며, 그 중 핵심 지시 부분("이전 1단계 NStack 아카이브를 참고하여... wiki.md에 의사결정을 기록해라.")이 보라색 네온 글로우로 깜빡이며 하이라이팅되는 SVG 탑재.
  - 지식 연계 명령이 작동 중임을 알리는 **⌨️ MIGRATION PROMPT INJECTED** 라벨 점등.

## 2. 실질적 본문 내용 (Exact Slide Content)

### ⌨️ "이전 1단계 NStack 아카이브를 적극 참고하여, 지식의 단절을 막아라"

1단계 바닐라 개발에 이어 집행되는 **[시연 2단계: React 마이그레이션]**의 출발점입니다. 개발자는 소스 코드를 에이전트에게 수동으로 넘겨주거나 구조를 처음부터 설명하는 노고를 거치지 않습니다. 대신, 1단계에서 굳건하게 쌓아두었던 지식 아카이브를 RAG로 찾아 삼키라는 명확한 **지식 상속 프롬프트**를 주입합니다.

- **💬 마이그레이션 연계 프롬프트 2 [Migration Prompt Data]**:

  ```markdown
  "방금 1단계에서 완성한 Vanilla JS Todo App 코드를 소스로 삼아서,
  Vite + React 19 + Zustand 모던 아키텍처로 포팅 및 마이그레이션을 진행해줘.

  이전 1단계 NStack 아카이브(todo-app/order.md 등)를 적극 참고하여,
  기술적 트레이드오프 의사결정을 wiki.md에 정확하게 기록해라."
  ```

- **⚡ RAG 검색 트리거 발동 [Knowledge Retrieval Trigger]**:
  - 에이전트는 이 프롬프트를 인식하는 즉시, 1단계에서 완료보고된 `todo-app/wiki.md` 에 기록된 "React 마이그레이션 시 DOM 직접 제어 로직의 React state 래핑 필요" Caveats 지식을 SwarmVault RAG 시맨틱 조회를 통해 초고속 인출하는 RAG 탐색 생태계를 가동합니다.

## 3. 스피치 노트 (Aside Speaker Notes)

_"마이그레이션 라이브 데모의 시작을 알리는 2차 프롬프트 실물 화면입니다. '바닐라 코드를 React 19와 Zustand 구조로 포팅해 달라'는 요구 사항 아래에, 아주 강력한 연계 조항이 박혀 있습니다. 바로 '이전 1단계 NStack 아카이브 문서를 적극 참고하라'는 명령입니다. 이 한 줄의 지식 상속 지시가 내려지는 즉시, AI 에이전트는 저장소를 리버스 엔지니어링하며 헤매는 무모한 행동을 스킵합니다. SwarmVault API를 기동하여 1단계 때 적재했던 `order.md`와 `wiki.md`를 3초 만에 시맨틱 쿼리해 뇌(Context)에 쏙 삼켜놓고 마이그레이션 설계도를 그릴 준비를 마치는 똑똑한 RAG 인지 생태계를 발동합니다."_
