# Slide 40: 지식 지도 — 프로젝트 연결 관계를 한눈에

## 1. 화면 정의 및 레이아웃 (Layout Specification)

- **레이아웃 구조**: 만유인력과 척력의 물리 법칙이 살아 숨 쉬며 사용자의 손끝에 입체적으로 출렁이고 반응하는 **D3 dynamic 지식 그래프 레이아웃 (D3 Physics Graph Layout)**.
- **비주얼 및 컴포넌트 구성**:
  - **좌측 비주얼**: 사파이어 네온과 에메랄드 네온 D3-force dynamic physics 3D 그래프 네트워크. 화면 중앙에 마우스 클릭 타겟 조준선이 특정 노드를 조준 클릭하는 순간, 주변의 모든 노드들이 자석 척력에 밀려 사방으로 둥실둥실 퍼지며 출렁거리고(Repulsion force), 클릭된 핵심 노드로 화면 전체가 우아하게 포커싱 빨려 들어가며 **Zoom-in** 되는 입체 모션 펄스 링 SVG 구현.
  - 물리 네트워크의 반응성을 상징하는 **🔗 D3 PHYSICAL NETWORK INTERACTIVE** 라벨 탑재.

## 2. 실질적 본문 내용 (Exact Slide Content)

### 🔗 D3 물리 시뮬레이션으로 출렁이며, 사용자의 손끝에 살아 움직이는 지식 네트워크

NAtlas GUI의 백미는 지식을 단순 정적 리스트가 아닌, 우주 공간의 성단처럼 스스로 숨 쉬고 작용하는 **D3-force dynamic physics 3D 네트워크 그래프**로 표현해 내는 점입니다. 단순한 이미지를 띄우는 것이 아니라, 브라우저 상에서 매 프레임마다 실제 물리학의 힘의 방정식을 실시간 연산하여 렌더링합니다.

- **🌌 D3-force 3대 물리 작용 아키텍처 [D3 Physics Forces]**:
  - **만유인력 (Gravity / Center Force)**: 모든 지식 노드들이 화면 밖으로 도망가지 않고 중앙에 묶여 은하수 성단을 형성하도록 중앙 인력을 작동시킵니다.
  - **자석 척력 (Charge / Repulsion Force)**: 노드들이 서로 겹쳐서 가독성을 파괴하지 않도록, 자석의 극성처럼 서로를 밀어내는 만유 척력을 인가해 칼정렬 팽창 상태를 유지합니다.
  - **스프링 장력 (Link Force / Tension)**: 이중 대괄호(`[[links]]`)로 엮인 노드 간에는 서로 당기는 스프링 고무줄 장력을 주어, 관련 피처들끼리 자연스럽게 묶이도록 배치합니다.
- **⚡ 노드 클릭 Zoom-in 트랜지션 [Interactive Click Transition]**:
  - 사용자가 특정 작업 노드를 마우스로 탭 하는 즉시, 물리 엔진은 클릭된 노드가 화면 중앙에 안착하도록 dynamic 궤적을 그리며 둥실 이동시킵니다.
  - 동시에 화면이 빨려 들어가는 **Zoom-in 모션**으로 포커스를 전환하며, React 위키 리더창에 해당 마크다운 상세 리더 뷰를 부드럽게 팝업 렌더링시킵니다.

## 3. 스피치 노트 (Aside Speaker Notes)

_"이번 슬라이드는 NAtlas GUI 아키텍처의 꽃이자 최절정, 바로 'D3 dynamic 물리 엔진 지식 노드맵'입니다. NAtlas 지식 지도는 단순 정적인 플로우 차트가 아닙니다. 브라우저 렌더링 엔진 상에서 매 초마다 물리학 힘의 방정식을 실시간 고속 연산하여 출렁이는 우주 성단 같은 3D 네트워크입니다. 노드들이 중앙에 묶이도록 '만유인력'을 주고, 서로 겹쳐 깨지지 않게 자석처럼 밀어내는 '척력'을 주었으며, 이중 대괄호 링크가 있는 노드 간에는 끈끈하게 당기는 '스프링 장력'을 주었습니다. 화면 좌측처럼 마우스 포인터가 노드를 클릭하면, 물리 시뮬레이터가 출렁이며 노드를 사방으로 밀어내고 클릭된 노드로 화면 전체가 우아하게 빨려 들어가는 Zoom-in 화면 전환 모션을 발휘합니다. 인간의 손끝에 유기적으로 반응하며 조직의 지식 흐름을 한눈에 체득할 수 있는 차세대 dynamic GUI의 극치입니다."_
