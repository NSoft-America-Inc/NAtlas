## 2. 실질적 본문 내용 (Exact Slide Content)

### 🧠 리버스 엔지니어링 없이, RAG 검색 단 3초 만에 설계 의도를 읽어내는 에이전트

전형적인 AI 마이그레이션 작업의 치명적인 한계는 "에이전트가 이전 개발 단계에서 엔지니어가 내렸던 고통스러운 트레이드오프나 주의 사항을 전혀 알지 못한다"는 것입니다. 소스 코드를 통째로 넘겨봐야 AI는 그 속에 담긴 '인간의 의도(Why)'를 파악할 수 없어 엉뚱한 설계를 반복합니다. NStack은 **SwarmVault RAG**를 기동해 이 단절을 완벽하게 봉합합니다.

- **🔍 RAG 지식 인출 및 주입 [Semantic Knowledge Ingestion]**:
  - 에이전트는 코드베이스에 무작정 진입하는 대신, SwarmVault API를 백그라운드에서 기동해 1단계의 **`todo-vanilla/wiki.md`**를 시맨틱 쿼리합니다.
  - 위키에 고밀도로 박제되어 있던 *"바닐라 JS의 명령형 DOM 제어 로직을 React 선언형 Hooks로 래핑 이관 시 State 오작동 주의"*라는 결정적인 **Caveats(제약 사항) 지식**을 뇌(Context)에 쏙 Citations 주입받습니다.
- **⚡ 실측 벤치마크: 토큰 95.29% 다이어트 입증 [Context Optimization]**:
  - 38개 파일의 무거운 코드를 로드하는 Naive 방식(78,689 토큰) 대신, RAG가 엄선한 3종 지식 문서(3,705 토큰)만 로드하여 **단 3초 만에 단기 기억을 증강**하고 비용을 극적으로 아꼈습니다.

## 3. 스피치 노트 (Aside Speaker Notes)

*"이번 장은 저희 프레젠테이션의 핵심 가치인 '지식 상속(RAG Rationale)'이 작동하는 정교한 원리를 보여주는 비주얼입니다. 보통 마이그레이션을 할 때 에이전트는 이전 바닐라 코드에 숨겨진 의도나 주의 사항을 알 길이 없습니다. 그래서 예전 코드를 한 줄씩 뜯어보는 리버스 엔지니어링 야근을 하거나 엉뚱한 구조로 꼬아놓기 일쑤죠. NStack은 이 문제를 SwarmVault RAG 주입기를 통해 기계적으로 완치했습니다. 에이전트가 분석을 누르는 순간, 백그라운드에서 RAG가 기동되어 1단계 때 정성껏 저장했던 `wiki.md` 문서에서 'DOM 제어를 React State로 래핑할 때 주의하라'는 핵심 Caveats 지식 조각만 레이저 광선처럼 뇌(Context)에 쏙 삼켜놓고 코딩에 진입합니다. 수만 줄의 소스 코드를 로드하던 7만 8천 개의 토큰이 단 **3,705 토큰**으로 줄어들어 **무려 95.29%의 토큰 다이어트**를 달성하는 물리적 실측치까지 완벽하게 입증해 낸 현장입니다."*
