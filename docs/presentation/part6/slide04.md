# Slide 55: 오늘부터 시작하기 — NStack 도입 3단계

## 1. 화면 정의 및 레이아웃 (Layout Specification)

- **레이아웃 구조**: 청중이 오늘 당장 실행할 수 있는 3단계를 크고 명확하게 보여주는 **3-Step CTA Layout**. 단계별 카드가 크게 가로로 나열되고, 각 카드에는 번호, 소요 시간, 핵심 행동이 담깁니다.
- **비주얼 및 컴포넌트 구성**:
  - **Step 1 카드 (스카이블루)**: 숫자 `1` + "Claude Code 설치 + 첫 대화" + "오늘 1시간".
  - **Step 2 카드 (퍼플)**: 숫자 `2` + "첫 번째 order.md 작성" + "내일 아침 5분".
  - **Step 3 카드 (에메랄드)**: 숫자 `3` + "NAtlas 설치 후 팀 공유" + "이번 주 내".
  - **하단 배너**: "지금 이 자리에서 QR 코드를 스캔하면, 설치 가이드가 바로 열립니다." 배지와 QR 코드 영역.
  - 상단 헤드라인: **"기다릴 필요 없습니다. 오늘 시작할 수 있습니다."**

## 2. 실질적 본문 내용 (Exact Slide Content)

### 🏁 지식의 소멸을 막는 첫걸음 — 지금 당장 할 수 있는 3가지

발표를 듣고 "좋은데, 나중에 해봐야지"라고 생각하는 순간, 지식은 또 사라집니다. NStack과 NAtlas는 오늘 당장 시작할 수 있습니다. 팀 전체 도입이 아니어도 됩니다. 나 혼자 먼저 써보는 것부터 시작하면 됩니다.

- **🔵 Step 1 — Claude Code 설치하고 첫 대화 (오늘, 약 1시간)**:
  - Claude Code CLI를 설치하고, 현재 진행 중인 작업 하나를 AI에게 맡겨봅니다.
  - "이걸 구현하기 전에 order.md를 먼저 작성해 줘"라고 요청하면 됩니다.
  - 처음이라 어색하더라도, 한 번만 해보면 흐름이 바로 잡힙니다.
- **🟣 Step 2 — 첫 번째 order.md 작성 (내일 아침, 약 5분)**:
  - 내일 할 작업을 시작하기 전, order.md 양식에 목적과 범위를 간단히 씁니다.
  - AI에게 보여주고 승인받으면 작업을 시작합니다.
  - 작업이 끝나면 결과를 wiki.md로 남깁니다.
- **🟢 Step 3 — NAtlas 설치 후 팀에 공유 (이번 주 내)**:
  - NAtlas를 로컬에 설치하고, 쌓인 문서들을 지식 지도로 확인합니다.
  - 팀원 한두 명과 함께 써보고, 좋으면 팀 전체로 확산합니다.

NStack과 NAtlas는 지금 당장 오늘 시작할 수 있습니다. 팀 전체 도입, 사내 프로세스 변경, 이런 큰 그림 먼저 아니어도 됩니다. 오늘 퇴근 전에 Claude Code 하나만 설치해보세요. 내일 아침 작업 시작할 때 order.md 하나만 써보세요. 이 두 가지만 해도 NStack의 핵심 흐름을 체험할 수 있습니다. 한 번 해보면 '아, 이래서 쓰는 거구나'가 됩니다. 질문이 있으시면 언제든지 말씀해주세요. 감사합니다."_
