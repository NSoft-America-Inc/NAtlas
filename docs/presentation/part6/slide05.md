# Slide 58: 다음 단계 — Phase 2 & Phase 3 중장기 로드맵

## 1. 화면 정의 및 레이아웃 (Layout Specification)

- **레이아웃 구조**: Phase 1 완료를 기점으로 Phase 2→3으로 이어지는 **3-Node Roadway Layout**. 원근법 3D 도로 위에 Phase 1(완료), Phase 2(진행 예정), Phase 3(최종 목표) 세 개의 노드가 순서대로 놓입니다.
- **비주얼 및 컴포넌트 구성**:
  - **좌측 로드맵 SVG**: 3D 원근감 도로 위에 세 개의 Phase 노드.
    - **Phase 1 (스카이블루, 완료)**: "Phase 1 (Done)" 표시. 이미 달성한 기점.
    - **Phase 2 (퍼플, 진행 예정)**: SQLite DB 아이콘이 노드 위에 떠 있음. 팀 공유 데이터베이스 고도화.
    - **Phase 3 (에메랄드, 최종)**: `.dmg/.exe` 패키지 박스 아이콘. 원클릭 인스톨러 배포.
  - **우측 설명 패널**: 각 Phase의 핵심 목표 두 가지를 간결하게 정리.
  - 도로 중앙 라인: 퍼플 네온 점선으로 연속성과 방향성 표현.

## 2. 실질적 본문 내용 (Exact Slide Content)

### 📅 Phase 1을 발판으로 — 중앙 공유 DB와 전사 배포로 전진

Phase 1 MVP는 성공적으로 완수됐습니다. 이제 NAtlas는 개인 로컬 환경에서 벗어나 팀 전체가 함께 쓰는 플랫폼으로 진화할 준비가 됐습니다.

- **🟣 Phase 2 — 관계형 SQLite 히스토리 통합 (차기)**:
  - 현재 로컬 파일 파싱 방식에서 `chats`와 `task_history` 테이블 간의 관계형 데이터 모델로 고도화합니다.
  - 팀 공유를 위한 중앙 클라우드 연동 기반을 구축하여, 여러 팀원이 동일한 지식 저장소를 바라볼 수 있게 됩니다.
  - 오프라인 우선 설계로 네트워크 단절 상황에서도 데이터 일관성을 보장합니다.
- **🟢 Phase 3 — 무중단 원클릭 인스톨러 배포 (최종)**:
  - `electron-builder` 파이프라인을 통해 macOS(`.dmg`)와 Windows(`.exe`) 전용 인스톨러를 패키징합니다.
  - 개발자가 아닌 PM이나 팀장도 더블클릭 한 번으로 NAtlas를 설치하고 바로 사용할 수 있게 됩니다.
  - 사내 배포 채널(사내망, Slack, 이메일)을 통한 전사 배포 완수.

## 3. 스피치 노트 (Aside Speaker Notes)

*"Phase 1에서 우리는 NAtlas의 핵심 기능을 증명했습니다. 이제 이것을 팀 전체가 실제로 쓸 수 있는 제품으로 만드는 것이 Phase 2와 3의 목표입니다. Phase 2는 '나 혼자 쓰는 도구'에서 '팀이 함께 쓰는 플랫폼'으로의 전환입니다. 데이터베이스를 팀 공유 가능한 구조로 고도화하는 것이 핵심입니다. Phase 3은 배포입니다. 지금은 개발자만 직접 설치할 수 있지만, 원클릭 인스톨러가 완성되면 개발자가 아닌 분들도 더블클릭 하나로 바로 쓸 수 있습니다. 이 로드맵이 완성되는 시점이 NAtlas가 NSoft의 전사 지식 플랫폼으로 자리잡는 시점입니다."*
