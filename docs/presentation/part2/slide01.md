# NStack이란? — 3분 만에 이해하는 핵심

## 1. 화면 정의 및 레이아웃 (Layout Specification)

- **레이아웃 구조**: NStack의 핵심 개념을 3단계 흐름으로 직관적으로 보여주는 **3-Step Flow Overview Layout**. 화면 중앙에 크게 흐르는 화살표 흐름도가 왼쪽에서 오른쪽으로 전개되고, 각 단계별 카드가 명확하게 구분됩니다.
- **비주얼 및 컴포넌트 구성**:
  - **상단 헤드라인**: "NStack = AI와 협업할 때 지식을 남기는 방법"
  - **중앙 흐름도**: `① 계획 (order.md)` → `② AI가 구현` → `③ 기록 (wiki.md)` 3단계가 큼직한 아이콘과 함께 좌→우 화살표로 연결.
  - **좌측 문제 카드 (붉은 테두리)**: "AI가 코드를 짜줬는데, 왜 이렇게 만들었는지 어디에도 없다"
  - **우측 결과 카드 (에메랄드 테두리)**: "NStack을 쓰면 개발할 때마다 이유가 자동으로 쌓인다"

## 2. 실질적 본문 내용 (Exact Slide Content)

### AI가 코드를 만들어도, 왜 만들었는지를 남기는 방법

NStack은 한 문장으로: **"AI와 협업할 때 지식이 자동으로 쌓이도록 만든 개발 방법론"**입니다.

3단계 흐름이 전부입니다:

**① 계획 — 오늘 무엇을 왜 만드는지 한 장으로 정리합니다 (order.md)**

- 5분이면 됩니다. AI가 이 지시서를 보고 방향을 잡습니다.

**② AI가 구현 — AI 에이전트가 지시서대로 코드를 만듭니다**

- 개발자는 결과가 맞는 방향인지 확인합니다.

**③ 기록 — 왜 이렇게 만들었는지를 문서로 남깁니다 (wiki.md)**

- 다음 번에 이 문서를 AI에게 주면, AI는 맥락을 이어받습니다.
- 팀원이 오면, 문서 하나로 1시간 안에 이해합니다.

이 3단계가 반복되면 — 개발할수록 지식이 쌓입니다. 지금처럼 개발할수록 지식이 사라지는 게 아니라.

## 3. 스피치 노트 (Aside Speaker Notes)

_"NStack이 무엇인지 한 문장으로 설명하면, 'AI와 협업할 때 지식을 체계적으로 남기는 방법론'입니다. 3단계가 전부입니다. 시작 전에 order.md로 오늘 뭘 왜 만드는지 정리하고, AI가 그걸 보고 구현하고, 끝나면 wiki.md로 왜 이렇게 만들었는지 기록합니다. 이 3단계가 반복될 때마다 팀의 지식이 한 층씩 쌓입니다. 개발할수록 지식이 사라지는 게 아니라, 개발할수록 지식이 쌓이는 구조가 됩니다."_
