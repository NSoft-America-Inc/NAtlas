# 형식만 있고 내용이 없는 문서는 자동으로 차단됩니다

## 1. 화면 정의 및 레이아웃 (Layout Specification)

- **레이아웃 구조**: 나쁜 예시와 차단 결과를 보여주는 **Block Example Layout**. 좌측에 차단되는 문서 예시, 우측에 차단 메시지.
- **비주얼 및 컴포넌트 구성**:
  - **좌측 (차단될 문서 예시, 붉은 테두리)**:

    ```
    ## 왜 이 작업을 합니까
    [여기에 작업 배경을 적으세요]

    ## 완료 기준
    TODO: 나중에 채우기
    ```

  - **중앙 차단 아이콘**: ❌ 빨간 X + "저장 차단됨"
  - **우측 차단 메시지 (터미널 스타일)**:
    ```
    ❌ 오류: 채워지지 않은 안내 문구가 발견되었습니다
    위치: ## 왜 이 작업을 합니까
    내용: "[여기에 작업 배경을 적으세요]"
    → 실제 내용을 채운 후 다시 시도하세요
    ```
  - **하단**: "형식을 복사했지만 내용을 채우지 않으면 — 저장이 안 됩니다."

## 2. 실질적 본문 내용 (Exact Slide Content)

### 가장 흔한 패턴 — 양식은 있는데 내용이 없다

문서 양식을 도입할 때 가장 많이 발생하는 문제:

1. 개발자가 양식 템플릿을 복사합니다
2. 바빠서 내용을 채우지 않고 그대로 올립니다
3. `[여기에 작업 배경을 적으세요]`, `TODO`, `나중에 작성` 같은 안내 문구가 그대로 남습니다
4. 형식은 있지만 지식은 없는 문서가 쌓입니다

NStack 자동 검사기는 이 상황을 차단합니다:

- 안내 문구나 TO DO가 그대로 남아있으면 → 저장이 차단됩니다
- 어느 섹션에서 발견됐는지 → 바로 표시됩니다
- 실제 내용을 채우면 → 통과됩니다

**핵심**: "쓴 척"하는 문서는 의미가 없습니다. NStack은 실제 내용이 있는 문서만 통과시킵니다.

## 3. 스피치 노트 (Aside Speaker Notes)

_"가장 많이 보이는 패턴이 있습니다. 양식을 복사했는데 내용을 채우지 않은 것입니다. '[여기에 작업 배경을 적으세요]', 'TODO' 같은 안내 문구가 그대로 남아있는 문서가 저장소에 올라옵니다. NStack 자동 검사기는 이런 안내 문구들을 인식하고 차단합니다. 어느 섹션에서 발견됐는지 바로 표시해줍니다. 실제 내용을 채우면 통과됩니다. 형식만 있는 문서는 지식이 없는 것과 같습니다. NStack은 진짜 내용이 있는 문서만 저장소에 쌓이게 만듭니다."_
