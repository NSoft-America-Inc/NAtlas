꼼수 등록이나 대충 복사해 넣은 문서를 지식 저장소 진입 단에서 기계적으로 차단하여,
지식 데이터베이스의 고품질 밀도를 안전하고 굳건히 유지합니다.

  • 방치된 설명 플레이스홀더 차단:
    `[여기에 작업의 배경...]` 같은 복사본 가이드 텍스트가 1글자만 남아 있어도 커밋 차단
  • 글자수 밀도(Density) 실질 계측:
    헤더 꼼수 기재를 없애기 위해 공백과 헤더 기호를 다 걷어내고 순수 바이트 검사
  • Fuzzy 지능형 치유 지원:
    오타 헤더를 수정해주고 알맹이는 살려 저장하는 `--heal` 복구 기능 내장
