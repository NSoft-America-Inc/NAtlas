NAtlas 아키텍처: 데스크탑 메인 프로세스와 Python Sidecar 생명주기

⛓️ 포트 충돌 및 크래시 예외 처리를 겸비한 공조 기전

Electron 메인 프로세스가 구동되는 즉시, Python FastAPI uvicorn 서버를
로컬 샌드박스로 자동 Spawn하고 포트 충돌 발생 시 중단 없는 kill 우회 처리를 완성합니다.

  • 충돌 포트 SIGKILL 및 재결합:
    포트 18420이 이미 점유되어 있을 경우, 이전 좀비 프로세스를 찾아 안전하게 kill 후 재생성
  • 자동 3회 헬스 체크 및 크래시 복구:
    FastAPI 프로세스 크래시 시 최대 3회 무중단 자동 복구 기동 지원
  • 프로세스 우아한 퇴장(Graceful Shutdown):
    Electron 앱 종료 감지 즉시 사이드카에 SIGTERM 명령 전달해 포트 해제
