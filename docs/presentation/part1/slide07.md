# OpenAI를 만든 사람도 같은 말을 했습니다

## 1. 화면 정의 및 레이아웃 (Layout Specification)

- **레이아웃 구조**: 인용구를 중심으로 배치하는 **Quote Spotlight Layout**. 좌측에 인물 소개, 우측에 큰 인용구. 권위자의 말을 화면 전면에 배치하여 신뢰감 형성.
- **비주얼 및 컴포넌트 구성**:
  - **좌측 인물 소개 패널**: 이름(안드레 카파시) + 경력 배지(OpenAI 공동 설립자 / 테슬라 전 AI 총괄) + 아이콘. "이 사람이 누구인지"를 먼저 명확히.
  - **우측 인용구 (큰 글씨)**: _"소스코드는 LLM에게 좋은 지도가 아닙니다. LLM이 필요한 것은 소스코드 옆에 나란히 존재하는, 극도로 정제된 기술 문서입니다."_
  - **하단 연결 문구**: "우리가 만든 NStack은 이 원칙을 실제 개발 워크플로우로 구현한 것입니다."

## 2. 실질적 본문 내용 (Exact Slide Content)

### 안드레 카파시 — OpenAI 공동 설립자, 테슬라 전 AI 총괄

AI 업계에서 가장 영향력 있는 인물 중 한 명인 안드레 카파시는 이런 말을 했습니다:

> _"소스코드는 LLM을 위한 좋은 지도가 아닙니다. LLM에게 필요한 것은 소스코드 옆에 나란히 존재하는, LLM만을 위해 극도로 정제된 기술 문서입니다."_

이 말의 의미는 간단합니다:

- AI에게 수만 줄의 코드를 주는 것은 AI에게 지도 대신 위성사진 전체를 주는 것과 같습니다
- AI가 잘 이해하려면 코드 자체보다, **코드가 왜 이런 구조인지를 설명하는 문서**가 필요합니다
- 이 문서는 AI를 위해 따로 정리되어야 합니다 — 코드에서 자동으로 읽히지 않습니다

우리가 만든 NStack은 바로 이 원칙을 실제 개발 워크플로우로 구현한 것입니다. 작업할 때마다 "왜 이렇게 만들었는지"가 자동으로 쌓이는 구조.

## 3. 스피치 노트 (Aside Speaker Notes)

_"안드레 카파시라는 이름, 들어보신 분 계십니까? OpenAI를 공동 창업하고, 테슬라에서 AI를 총괄했던 분입니다. AI 분야에서 가장 신뢰받는 목소리 중 하나입니다. 이분이 이런 말을 했습니다. '소스코드는 LLM을 위한 좋은 지도가 아니다. LLM이 필요한 건 소스코드 옆에 나란히 존재하는, LLM만을 위해 정제된 기술 문서다.' 우리가 겪는 문제를 전문가도 같은 방식으로 진단한 겁니다. 코드 자체가 아니라, 코드 옆에 있어야 하는 설명 문서가 필요하다는 것. NStack은 이걸 개발 워크플로우로 만든 것입니다."_
