# Slide 7: 안드레 카파시의 경고 - '소스코드는 LLM을 위한 좋은 지도가 아닙니다'

## 1. 화면 정의 및 레이아웃 (Layout Specification)

- **레이아웃 구조**: 수많은 날것의 소스코드 무더기와 정제되어 컴파일된 기술 지식 도서를 극적으로 대조 분할하는 **코드 숲 vs 구조화 지식 2열 뷰포트 (Code Forest vs Structured Book)**. 좌우의 조명과 대조비를 극대화하여 시각적 설득력을 최고조로 확보합니다.
- **비주얼 및 컴포넌트 구성**:
  - **좌측 (Raw Code Forest)**: 
    - 칠흑같이 어두운 배경 위로 난해하게 얽혀서 자라나는 앙상한 겨울 나뭇가지 형태의 코드 트리. 
    - LLM이 이해하기 어려운 기계적 코드 라인의 파편을 차갑게 묘사.
  - **우측 (Structured Book - Purple Glow Theme)**: 
    - 은은하고 웅장한 퍼플 네온 글로우가 뿜어져 나오는 지식 위키 도서 다이어그램. 
    - 코드의 역사, 설계의 이유, 장애 Caves가 단아한 노드로 파싱되어 흐르는 광선 빔 연동.

## 2. 실질적 본문 내용 (Exact Slide Content)

### 📖 LLM만을 위해 정제된 '기계 가독형 지식' (Machine-Readable Knowledge)

테슬라의 전 AI 디렉터이자 OpenAI 공동 설립자인 안드레 카파시(Andre Karpathy)는 일찍이 **"소스코드에만 의존하여 에이전트와 코딩하는 것의 치명적인 한계"**를 통찰하고, AI 시대에 조직이 살아남기 위한 새로운 기술 지식의 패러다임을 제안했습니다.

- **🚫 날것의 코드가 지닌 한계 [Terrifying Map for LLM]**: 
  - 수천~수만 줄의 소스 코드는 LLM에게 너무 복잡하고 노이즈가 많은 지도(Map)입니다. 
  - LLM은 코드 자체만 보고 이전 개발자들의 트레이드오프나 깊은 설계 인과관계를 단번에 완전무결하게 해독해 내지 못합니다.
- **💡 LLMWiki 기술 위키의 당위성 [Highly-dense Tech Wiki]**: 
  - AI 에이전트가 단 3초 만에 시스템 전체 구조를 이해하고 가장 안전하게 작업할 수 있도록, 소스코드 옆에 병렬로 **"LLM만을 위해 극도로 요약 정제된 기술 마크다운 위키(LLMWiki)"**를 영구 축적해야 합니다.
  - NStack은 이 카파시의 비전을 전사 최초로 표준화하여, 에이전트가 코드를 쓰기 전 지식 문서를 반드시 흡수하고 환원하도록 통제하는 **지식 순환 루프**를 완벽하게 실현하였습니다.

## 3. 스피치 노트 (Aside Speaker Notes)

*"테슬라 AI 디렉터였던 안드레 카파시는 매우 중요한 경고를 날렸습니다. 바로 '날것의 소스코드는 인공지능에게 있어 최악의 지도와 같다'는 사실입니다. AI에게 코드 수만 줄을 통째로 던져주고 분석하라고 하면, 컨텍스트 용량은 용량대로 터지고 비용은 폭증하며 정작 중요한 아키텍처 인과관계는 해독하지 못합니다. 카파시는 소스코드와 병렬로, 오직 LLM의 고속 인지와 토큰 절약을 위해 완벽히 정제된 기계 가독형 기술 문서, 즉 'LLMWiki'가 저장소마다 영구 보존되어야 한다고 역설했습니다. NStack은 바로 이 카파시의 LLMWiki 아키텍처를 전사 레벨로 정식 실현하여, 에이전트의 효율성과 안정성을 기계적 영역에서 증명해냈습니다."*
