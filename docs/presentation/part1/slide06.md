# Slide 6: 대화형 코딩의 병목 - '컨텍스트 오버로드'의 한계

## 1. 화면 정의 및 레이아웃 (Layout Specification)

- **레이아웃 구조**: 긴 대화창과 코드 더미에 짓눌린 AI 연산 상태를 가시화하는 **프로세서 과열 경보 대시보드 레이아웃 (CPU Overload Dashboard)**. 좌측의 강렬한 붉은색 경보 비주얼과 우측의 정밀한 병인 분석 텍스트로 화면을 빽빽하고 유기적으로 장악합니다.
- **비주얼 및 컴포넌트 구성**:
  - **좌측 비주얼**: `CONTEXT OVERFLOW (100%)`가 선명하게 붉은색 네온으로 발광하고 과열 상태의 CPU 기판 칩셋이 네온 글로우로 번쩍이는 모션 SVG. 
  - 버퍼에 가득 찬 데이터 패킷들이 오버플로우되어 손실되는 입체 비주얼 렌더링.

## 2. 실질적 본문 내용 (Exact Slide Content)

### 📈 누적 대화 세션의 컨텍스트 임계점 초과와 지시 일관성 붕괴

단순 대화형(Chat-based) 환경에서 에이전트와 긴 주기의 개발 세션을 이어갈 경우, 대화창이 끝없이 아래로 길어지며 **AI 컨텍스트 윈도우(Context Window)의 오버헤드**가 강제 임계점을 넘게 됩니다. 이 임계점 초과는 단순 요금 문제를 넘어, 시스템 전체의 아키텍처 안전성을 붕괴시키는 **3대 병목 현상**을 초래합니다.

- **🚫 단기 기억 상실 [Forgotten Instructions]**: 
  - 세션 초기에 개발자가 강력히 제약해 둔 라이브러리 버전 규칙, DB 스키마 예외 처리 지침 등이 긴 대화 더미 속에서 소실되어 AI가 이전의 지시를 잊어먹기 시작합니다.
- **📉 지시 일관성 붕괴 [Inconsistent Behavior]**: 
  - AI 에이전트의 작동 지향점(Alignment)이 깨지면서 방금 합의한 스토어 리팩토링 규칙 대신 레거시 방식의 코드를 무절제하게 임시로 짜 넣는 불안정한 동작을 일삼습니다.
- **🔥 무절제한 코드 오동작 [Scope Creep & Side Effects]**: 
  - 통제선을 잃어버린 에이전트가 작업 범위(Scope)를 무절제하게 넓혀, 타 피처 영역의 정상적인 기존 코드를 찌그러뜨리는 등 예측할 수 없는 심각한 사이드 이펙트(Side Effect)를 양산합니다.

## 3. 스피치 노트 (Aside Speaker Notes)

*"대화형 코딩을 길게 해보신 분들은 모두 뼈저리게 공감하실 겁니다. 에이전트와 한두 시간 넘게 대화를 나누며 개발을 하다 보면, 어느 순간 AI가 똑똑함을 잃고 방금 한 말도 잊은 채 엉뚱한 코드를 짜며 버벅이기 시작합니다. 바로 '컨텍스트 오버로드'의 병목이 터진 것입니다. AI의 제한된 단기 기억 장치인 컨텍스트 윈도우가 누적된 대화와 코드 더미로 가득 차면서 지시의 일관성이 붕괴된 것이죠. 이로 인해 에이전트는 무절제하게 넓은 범위의 파일을 건드려 정상적으로 돌던 핵심 코드를 깨뜨리고, 결국 개발자가 이를 수동으로 고치는 더 큰 지옥에 빠지게 됩니다. 우리는 에이전트의 단기 기억 오버헤드를 물리적으로 통제해야만 합니다."*
