"Raw codebase is NOT a great map for LLMs. LLMs need condensed, structured Machine-readable Knowledge."

📖 안드레 카파시의 LLMWiki 비전과 아카이브 필요성

테슬라 AI 디렉터이자 OpenAI 창립자인 안드레 카파시는 일찍이
소스코드에만 의존하는 AI 코딩의 물리적 한계를 정면으로 경고한 바 있습니다.

  • 기계 가독형 지식(Machine-readable Knowledge):
    LLM이 거대한 레거시를 읽는 대신 압축 요약된 아키텍처 맥락을 소화하게 함
  • 병렬형 기술 위키(LLMWiki) 축적:
    소스 코드와 나란히 흐르는 전사 지식 3종 아티팩트를 SQLite/Markdown으로 영구 보존
  • NStack 구현체의 탄생 근거:
    카파시의 지식 맵 철학을 전사 Git 훅과 RAG 시스템에 정식 탑재하여 실현화
NStack ➔ NAtlas E2E 지식 파이프라인 소개 NSoft America, Inc.
"안드레 카파시는 일찍이 소스코드에만 의존하는 AI 코딩의 구조적 한계를 지적했습니다. LLM은 수천 줄의 날것 그대로의 코드를 통째로 읽어 분석하는 것보다, 코드의 역사, 의도, 트레이드오프를 압축 요약해놓은 'LLM 전용 기술 마크다운 위키(LLMWiki)'를 코드와 병렬로 영구 축적하는 것이 에이전트 효율성 제고에 필수적이라고 분석했습니다."
