# Slide 45: Settings 탭 — 처음 한 번, 내 위키 폴더를 NAtlas에 연결

## 1. 화면 정의 및 레이아웃 (Layout Specification)

- **레이아웃 구조**: NAtlas를 처음 실행했을 때 딱 한 번 해야 할 설정 — 내 컴퓨터의 위키 폴더 경로를 지정하는 과정을 **3단계 순서도 레이아웃**으로 보여줍니다.
- **비주얼 및 컴포넌트 구성**:
  - **좌측 비주얼**: Settings 탭 UI 화면. 폴더 경로 입력 필드 옆 📂 아이콘 클릭 → 탐색기 창 팝업 → 경로가 입력창에 자동 입력 → 저장 버튼 클릭 → "🔒 설정 완료" 배지. 3단계 흐름이 화살표로 연결.
  - **우측 설명 패널**: "이걸 한 번만 하면 다음부터는 자동" 강조 텍스트와 함께 각 단계 설명.

## 2. 실질적 본문 내용 (Exact Slide Content)

### 🔒 처음 한 번만 — 내 위키 폴더 경로를 알려주면 그 다음은 자동

NAtlas를 처음 설치하고 한 가지만 설정하면 됩니다. "내 컴퓨터 어디에 위키 문서들이 있는지"를 알려주는 것입니다. 이 설정은 딱 한 번만 하면 됩니다. 그 다음부터는 NAtlas를 열 때마다 자동으로 그 폴더를 읽어 지식 지도를 보여줍니다.

- **📂 설정 방법 — 3단계**:
  - **Step 1**: Settings 탭을 열고 📂 폴더 아이콘을 클릭합니다.
  - **Step 2**: 내 컴퓨터의 탐색기 창이 열립니다. 위키 문서가 있는 폴더를 선택합니다.
  - **Step 3**: 저장 버튼을 누르면 완료. 앱을 재시작할 필요가 없습니다.
- **✨ 설정 후 바로 달라지는 것**:
  - Documents 탭에 위키 문서들이 즉시 목록으로 나타납니다.
  - 3D 지식 지도에 해당 폴더의 프로젝트들이 노드로 나타납니다.
  - 팀원마다 위키 폴더 경로가 달라도 각자 자신의 경로를 설정해서 쓸 수 있습니다.

## 3. 스피치 노트 (Aside Speaker Notes)

_"NAtlas를 처음 설치하고 해야 할 일은 딱 하나입니다. Settings 탭을 열고 '내 위키 폴더가 어디 있는지' 알려주는 것입니다. 폴더 아이콘을 클릭하면 탐색기가 열리고, 폴더를 선택하면 끝입니다. 저장 버튼을 누르면 앱을 껐다 켤 필요도 없이 바로 Documents 탭과 지식 지도가 업데이트됩니다. 팀원들마다 컴퓨터에 폴더 위치가 다를 수 있잖아요. 그래서 각자 자신의 경로를 설정해서 쓰면 됩니다. 이 설정은 딱 한 번만 하면 그 다음부터는 NAtlas가 알아서 기억합니다."_
