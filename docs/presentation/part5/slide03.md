# Slide 43: Documents 탭 — 문서가 항상 최신 상태를 유지하는 방법

## 1. 화면 정의 및 레이아웃 (Layout Specification)

- **레이아웃 구조**: 로컬 서버의 메모리 및 API 과부하를 원천 방어하면서도 언제나 최신의 무결성 지식을 쾌적하게 렌더링하는 **TanStack Query useQuery Cache Flow Layout**.
- **비주얼 및 컴포넌트 구성**:
  - **좌측 비주얼**: React 클라이언트와 FastAPI 로컬 백엔드 간의 데이터 교류 흐름도 SVG. 클라이언트 내부의 **TanStack Query Cache Layer**에 저장된 캐시 메모리 허브(에메랄드색 글로우 링)가 존재하여, 첫 요청 시에는 18420 포트 백엔드와 연결(GET /documents)하여 신선한 데이터를 저장하고, 30초 타이머가 펄스 회전하면서 30초 주기로 백그라운드 리프레시(Refetch)를 수행하는 스마트 캐싱 모션 그래픽스.
  - 백그라운드 스케줄링의 안전성을 보장하는 **⚡ 30s CACHE SYNC TICKING** 네온 배지 탑재.

## 2. 실질적 본문 내용 (Exact Slide Content)

### 💾 TanStack Query useQuery 캐싱 및 30초 폴링 주기로 구현된 초경량 고성능 지식 싱크로나이저

NAtlas GUI는 로컬 백엔드 서버 포트 18420과의 통신 비효율을 극복하고, 클라이언트의 상태 전이를 고속으로 제어하기 위해 **TanStack Query (React Query)의 useQuery 캐시 레이아웃**을 프론트엔드 핵심 아키텍처로 내장하고 있습니다.

- **🗃️ TanStack Query 캐시 메모리 가동 [Cache Layer & Performance]**:
  - **초고속 컴포넌트 렌더링 (Zero-Lag Query)**: 사용자가 탭을 전환하거나 다른 지식 노드로 커서를 이동했다가 Documents 탭으로 다시 돌아올 때, API를 매번 새로 쏘지 않고 클라이언트 메모리에 즉각 사용 가능한 캐시 데이터를 0.001초 만에 다이렉트 바인딩해 깜빡임 없는 극상의 UX를 제공합니다.
  - **Stale-While-Revalidate 사상**: 화면에는 우선 캐시 데이터를 즉시 표출해 가용성을 보장하는 동시에, 백그라운드에서는 로컬 백엔드의 상태 변경 여부를 은밀하게 검사하여 데이터 불일치 가능성을 완전히 제거합니다.
- **🔄 30초 주기 Background Refetch [30-Second Sync Loop]**:
  - **동기화 타이머 가동 (`refetchInterval: 30000`)**: AI 에이전트의 CLI 태스크 기동 등으로 인해 백그라운드에서 신규 지식 문서가 추가/수정되는 시나리오를 대비하여, 30초마다 1회씩 백그라운드에서 `GET /documents` API를 호출하는 헬스 폴링 루프가 동작합니다.
  - **UI 무중단 업데이트**: 백그라운드 fetch가 완료되었을 때, 실제 변경된 데이터 델타(Delta)가 존재할 경우에만 컴포넌트 트리를 부분적으로 업데이트하여, D3 3D 물리 시뮬레이션의 계산 프레임이 밀리거나 버벅거리는 프레임 드랍(Frame-drop) 현상을 원천 방지합니다.

## 3. 스피치 노트 (Aside Speaker Notes)

_"이번에는 NAtlas GUI가 지상 최고의 초고속 응답 속도와 완벽한 데이터 동기화를 동시에 달성한 비결, 바로 'TanStack Query 기반의 useQuery 캐시 아키텍처'입니다. NAtlas가 구동되는 동안, 로컬 FastAPI 서버는 18420 포트를 열고 대기합니다. 이때 React 클라이언트가 화면을 그릴 때마다 백엔드로 직접 조회 요청을 무차별적으로 날리게 되면 CPU 과열과 응답 지연이 수반됩니다. NAtlas는 프론트엔드에 TanStack Query 캐시 엔진을 탑재해 이 병목을 완치했습니다. 사용자가 탭을 클릭하거나 노드를 탐색할 때, 이미 가져온 지식 데이터는 메모리 캐시로부터 단 1밀리초 만에 즉시 렌더링되어 사용자는 무중단 고속 서핑을 즐길 수 있습니다. 그리고 화면 뒤에서는 백그라운드로 30초 타이머가 실시간 펄스 회전합니다. 30초 주기가 만료될 때마다 백엔드의 최신 SQLite 상태와 'GET /documents' API로 동기화를 확인하는 폴링을 수행합니다. 데이터 변경이 감지되었을 때만 똑똑하게 델타 렌더링을 적용하므로, 무겁게 돌고 있는 D3 3D 물리 연산이 프레임 드랍으로 툭툭 끊기는 현상 없이 아름답고 부드러운 상태 동기화를 무중단으로 성취했습니다."_
