# Slide 41: 지식 지도에서 문서로 — 더블클릭 한 번에 바로 이동

## 1. 화면 정의 및 레이아웃 (Layout Specification)

- **레이아웃 구조**: 3D 지식 지도에서 노드를 더블클릭하면 해당 문서가 즉시 열리는 장면을 **Before → After 전환 애니메이션**으로 보여주는 레이아웃. 왼쪽에 지식 지도(노드 클릭), 오른쪽에 문서가 열리는 결과 화면이 나란히 배치됩니다.
- **비주얼 및 컴포넌트 구성**:
  - **좌측 비주얼**: 3D 지식 지도 위 노드에 더블클릭 파동(동심원)이 퍼지는 SVG 애니메이션. 노드 주위에 "더블클릭" 텍스트 안내 배지.
  - **중앙 전환 화살표**: 퍼플 네온 화살표(`⚡ 즉시 전환`)가 전환 방향을 표시.
  - **우측 비주얼**: 문서 탭으로 전환된 화면 — wiki.md 마크다운 내용이 슬라이딩하며 열리는 모습.

## 2. 실질적 본문 내용 (Exact Slide Content)

### ⚡ 원하는 문서로 순간이동 — 지식 지도에서 더블클릭하면 끝

3D 지식 지도는 보기만 하는 그림이 아닙니다. 궁금한 프로젝트 노드를 더블클릭하는 순간, 해당 프로젝트의 문서 탭이 즉시 열립니다. 검색창을 찾을 필요도, 메뉴를 클릭할 필요도 없습니다.

- **🎯 더블클릭 한 번으로 문서 열기**:
  - 3D 지식 지도에서 보고 싶은 노드(프로젝트)를 더블클릭합니다.
  - 지식 지도가 부드럽게 뒤로 물러나며, 해당 프로젝트의 wiki.md 문서가 화면 전면에 자연스럽게 슬라이딩하며 열립니다.
  - 지도와 문서 사이의 맥락이 끊기지 않습니다. "어디서 왔는지" 기억하며 이동합니다.
- **✨ 화면 전환이 매끄러운 이유**:
  - 기존의 웹 앱처럼 페이지 전체가 깜빡이며 새로 로딩되는 방식이 아닙니다.
  - 지식 지도 → 문서, 문서 → 지식 지도 어느 방향이든 한 화면 안에서 자연스럽게 전환됩니다.
  - 처음 쓰는 사람도 "어떻게 여는지"를 따로 배울 필요 없이 직관적으로 작동합니다.

## 3. 스피치 노트 (Aside Speaker Notes)

_"3D 지식 지도는 보기만 하는 화면이 아닙니다. 직접 클릭해서 들어갈 수 있습니다. 궁금한 프로젝트 노드를 더블클릭하는 순간 — 지식 지도가 뒤로 물러나고 해당 문서가 앞으로 나옵니다. 마치 지도를 보다가 원하는 곳으로 순간이동하는 것처럼요. 화면이 깜빡이거나 새로 로딩되는 것도 없습니다. 그냥 자연스럽게 전환됩니다. 처음 써보는 사람도 '어떻게 여는 거지?'라고 생각할 겨를이 없습니다. 더블클릭하면 바로 열리니까요."_
