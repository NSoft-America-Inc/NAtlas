# Slide 42: 내가 원하는 대로 — 화면 구성을 자유롭게 조절

## 1. 화면 정의 및 레이아웃 (Layout Specification)

- **레이아웃 구조**: NAtlas의 3구역 화면(사이드바, 문서 목록, 지식 지도)을 마우스 드래그로 자유롭게 넓히고 줄이는 모습을 보여주는 **Panel Resize Demo Layout**. 드래그 전/후 화면 비율 변화를 나란히 비교합니다.
- **비주얼 및 컴포넌트 구성**:
  - **좌측 비주얼**: 3구역으로 나뉜 NAtlas 화면 와이어프레임. 구역 경계선에 마우스가 올라가면 노란 경계선이 활성화되고, 드래그로 우측 지식 지도 영역이 넓어지는 애니메이션.
  - **상태 배지**: "⚡ 지식 지도가 깨지지 않고 자동 재정렬" 설명 배지 표시.
  - **우측**: 각 구역의 역할 설명 텍스트 패널.

## 2. 실질적 본문 내용 (Exact Slide Content)

### 📐 화면을 내 작업 방식에 맞게 — 드래그 한 번으로 비율 조절

NAtlas 화면은 세 구역으로 나뉩니다: 왼쪽 탭 메뉴, 가운데 문서 목록, 오른쪽 3D 지식 지도. 이 구역 사이의 경계선을 마우스로 드래그하면 원하는 대로 넓이를 조절할 수 있습니다.

- **🎛️ 세 구역의 역할**:
  - **왼쪽 사이드바**: Documents / Update / Settings 탭 전환 네비게이션.
  - **가운데 문서 목록**: 검색 가능한 wiki.md, order.md 파일 목록.
  - **오른쪽 지식 지도**: 3D 프로젝트 연결 관계 시각화 캔버스.
- **✨ 조절해도 지식 지도가 깨지지 않는 이유**:
  - 오른쪽 영역을 넓히거나 줄여도 3D 지식 지도는 새로운 크기에 맞게 자동으로 재정렬됩니다.
  - 노드들이 화면 밖으로 날아가거나 찌그러지지 않습니다.
  - 문서를 많이 볼 때는 가운데를 넓게, 지식 지도를 탐색할 때는 오른쪽을 넓게 — 상황에 따라 조절해서 씁니다.

## 3. 스피치 노트 (Aside Speaker Notes)

_"NAtlas 화면은 고정된 게 아닙니다. 세 구역 사이의 경계선을 마우스로 드래그하면 비율을 자유롭게 바꿀 수 있습니다. 문서를 집중해서 읽고 싶을 때는 가운데 영역을 넓히고, 프로젝트 간 연결 관계를 보고 싶을 때는 오른쪽 지식 지도를 크게 키우면 됩니다. 한 가지 중요한 점은, 오른쪽 영역의 크기를 바꿔도 3D 지식 지도가 흐트러지지 않는다는 겁니다. 새 크기에 맞게 자동으로 중앙 정렬해서 보기 좋게 유지됩니다. 이런 세심한 부분들이 NAtlas를 실제로 매일 쓰고 싶은 도구로 만들어 줍니다."_
